# FreeWatch App Store Listing & Download Site

This is the independent Apple App Store styled product landing page for **FreeWatch**, designed following the native iOS App Store design system with full Light & Dark mode support, ratings, What's New changelog, preview screenshot cards, and 1-tap APK downloading.

## Local Development
```bash
npm install
npm run dev
```

## Deployment
Deploy to Vercel, Netlify, or any static hosting provider:
```bash
npm run build
```
Or import this directory directly into your Vercel Dashboard as an independent project.
